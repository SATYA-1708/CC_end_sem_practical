# C++ End-Semester Practicals

A small coursework collection containing C++ solutions for a climbing-stairs exercise and a sliding-window-maximum exercise, plus screenshots of selected outputs.

## Files

- `climbingstairs.cpp` — climbing-stairs solution.
- `slidingwindowmax.cpp` — sliding-window maximum solution.
- `Screenshot *.png` — output evidence supplied with the exercises.

## Use

Both `.cpp` files contain judge-style `Solution` classes rather than standalone programs. Submit each class with the required standard headers and platform harness, or add a local test `main()` before compiling.

- `climbStairs` uses O(n) time and O(1) extra space.
- `maxSlidingWindow` uses a deque and O(n) time with O(k) auxiliary space.

No external dependencies or deployment configuration are included.
